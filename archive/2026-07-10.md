# GitHub Trending — 2026-07-10

## TL;DR
The "agent skills" ecosystem dominates today's list — three of the top ten repos (addyosmani/agent-skills, mattpocock/skills, obra/superpowers) are all about packaging reusable skills and methodology for AI coding agents, alongside an MCP server for terminal/filesystem access. Otherwise it's a strong showing for long-established C++ and systems infrastructure (Abseil, yaml-cpp, Catch2, Asio, TypeScript), plus Bun continuing its steady climb.
