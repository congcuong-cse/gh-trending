# GitHub Trending — 2026-07-03

## TL;DR
AI-agent tooling dominates today's list — pentesting agents, token-compression tricks for Claude Code, MCP integrations, and cross-tool bridges (Codex-from-Claude-Code) all feature prominently. Python and TypeScript are the most common languages, and long-standing infrastructure projects (Elasticsearch, Ansible, actions/checkout) sit alongside brand-new agent-ecosystem repos.

## Top 10

### 1. usestrix/strix  (+2,804 stars today)
An open-source AI penetration testing tool that automatically finds and helps fix vulnerabilities in your app — part of the growing wave of AI agents applied to offensive security.

### 2. openai/codex-plugin-cc  (+629 stars today)
A plugin that lets you invoke OpenAI's Codex from inside Claude Code, so you can have Codex review code or take on delegated tasks without leaving your Claude Code workflow.

### 3. JuliusBrussee/caveman  (+2,851 stars today)
A Claude Code skill that rewrites prompts in terse "caveman speak" to cut token usage by roughly 65%, part of the broader trend toward token-efficient agent prompting.

### 4. elastic/elasticsearch  (+77 stars today)
The well-established free and open-source distributed RESTful search engine, still picking up steady daily interest.

### 5. actions/checkout  (+129 stars today)
GitHub's official Action for checking out a repository in CI workflows — a foundational building block for nearly every GitHub Actions pipeline.

### 6. ChromeDevTools/chrome-devtools-mcp  (+404 stars today)
Exposes Chrome DevTools capabilities via MCP, letting coding agents drive and inspect a real browser — useful for automated web testing and debugging by AI agents.

### 7. ansible/ansible  (+50 stars today)
The widely used, radically simple IT automation platform for deploying and configuring applications and systems.

### 8. facebook/astryx  (+943 stars today)
An open-source, fully customizable design system built to be "agent ready," suggesting design systems are increasingly being adapted for AI-driven UI generation.

### 9. rommapp/romm  (+236 stars today)
A beautiful, self-hosted ROM manager and player for organizing and playing retro game collections.

### 10. harvard-edge/cs249r_book  (+792 stars today)
