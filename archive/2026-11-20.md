# GitHub Trending — 2026-11-20

## TL;DR
Agent tooling dominates again: six of the top 10 are skills, plugins, or
infrastructure for AI coding agents (Claude Code, Cursor, and others). Python leads with four
entries, followed by TypeScript with two. The Claude Code bug-hunting bundle stays at #1 (+1,660),
and firecrawl posts the second-biggest gain (+1,226). nginx and OpenVINO are the only
classic infrastructure projects on the list.

## Top 10

### 1. elementalsouls/Claude-BugHunter  (+1,660 stars today)
A Claude Code skill bundle for bug hunting and external red-team work: 82 skills, 15 slash
commands, and patterns drawn from disclosed vulnerability reports. #1 for a second digest in a row.

### 2. obra/superpowers  (+888 stars today)
An agentic skills framework and software-development methodology. At 322,799 total stars it is
by far the largest repo on the list.

### 3. HKUDS/CLI-Anything  (+774 stars today)
Aims to make any software "agent-native" by giving it a CLI that agents can drive, with a
companion hub of CLIs.

### 4. jingyaogong/minimind  (+841 stars today)
An educational project for training a small 64M-parameter LLM from scratch in about two hours.
Useful for learning how LLM training works end to end.

### 5. cursor/plugins  (+292 stars today)
Cursor's plugin specification and its official plugins, the base for an extension ecosystem
around the editor's agent.

### 6. firecrawl/firecrawl  (+1,226 stars today)
A search and scraping API that gives agents web data and 550+ data providers through one
interface. The day's second-biggest gain.

### 7. nginx/nginx  (+246 stars today)
The official open-source NGINX repository. The web server is a long-standing piece of
infrastructure, and it shows up here with steady interest.

### 8. openvinotoolkit/openvino  (+219 stars today)
Intel's open-source toolkit for optimizing and deploying AI inference across hardware.

### 9. cathrynlavery/diagram-design  (+634 stars today)
Editorial-style diagram design for AI coding agents (Claude Code, Codex, Copilot, Cursor and
more), with 45 diagram types.

### 10. mvanhorn/last30days-skill  (+685 stars today)
An agent skill that researches a topic across Reddit, X, YouTube, HN, Polymarket and the web,
then summarizes it.
