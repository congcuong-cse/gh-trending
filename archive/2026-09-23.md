# GitHub Trending - 2026-09-23

## TL;DR
Agent infrastructure dominates the board today — orchestration runtimes, agent harnesses, agent-native CLIs, and "office" runtimes built for AI agents to drive rather than humans. Anthropic itself has an entry, and Claude-adjacent tooling (a Claude Code config/monitoring CLI) also cracked the top 10. Python and TypeScript are the most common languages (four entries each), with Go rounding things out. Star-count-wise it's a wide spread: from a fast-rising newcomer at under 10k stars to `obra/superpowers`, already sitting at nearly 300k.

## Top 10

### 1. anthropics/financial-services (+665 stars today)
An Anthropic-published repository for financial-services use cases; no description is set on the repo yet, but it's already pulling strong daily growth.

### 2. google/ax (+1,542 stars today)
Google's open agentic orchestration runtime, written in Go — infrastructure for coordinating multiple AI agents.

### 3. davila7/claude-code-templates (+393 stars today)
A CLI tool for configuring and monitoring Claude Code, helping developers manage setup and observability for their Claude Code usage.

### 4. BuilderIO/agent-native (+135 stars today)
A TypeScript framework from Builder.io for building "agent-native" apps — applications designed around AI agents as first-class users.

### 5. obra/superpowers (+485 stars today)
A shell-based agentic skills framework and software development methodology, already the largest repo on today's list by total stars (290k+).

### 6. dream-num/univer (+1,140 stars today)
Billed as an "Office Harness for AI Agents," bundling spreadsheets, docs, slides, canvas, relational tables, and PDFs into one runtime for agents to operate on.

### 7. Open-Dev-Society/OpenStock (+379 stars today)
An open-source alternative to paid market-data platforms, offering real-time prices, custom alerts, and company insights, positioned as free forever.

### 8. agent-substrate/substrate (+560 stars today)
The core system behind "Agent Substrate," a Go project providing foundational infrastructure for running agents.

### 9. strands-agents/harness-sdk (+96 stars today)
An open-source SDK for building and controlling an agent harness end-to-end, supporting Python and TypeScript across any model or cloud.

### 10. HKUDS/CLI-Anything (+41 stars today)
A project aiming to make "ALL software agent-native" by turning arbitrary CLIs into agent-operable tools, paired with a companion CLI-Hub site.
