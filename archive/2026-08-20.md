# GitHub Trending — 2026-08-20

## TL;DR
AI agent tooling dominates today's chart yet again — skills frameworks, agent memory systems, and multi-agent harnesses fill six of the top ten slots. Shell and Rust both had strong showings, and two long-established mega-repos (Anthropic-adjacent "skills"/"superpowers" projects with 200k+ stars) kept climbing even at that scale. A local-first Rust hardware utility and an AI video generator round out the more unusual entries.

## Top 10

### 1. modular/modular (+340 stars today)
The Modular Platform, including MAX and the Mojo language — infrastructure for building and running AI models.

### 2. mattpocock/skills (+2,267 stars today)
A large, popular collection of reusable "skills" for coding agents, shared directly from the author's own `.agents` directory.

### 3. AprilNEA/OpenLogi (+1,540 stars today)
A native, local-first alternative to Logitech Options+ written in Rust, remapping mouse buttons, DPI, and SmartShift over HID++ with no account or telemetry required.

### 4. obra/superpowers (+749 stars today)
An agentic skills framework and software development methodology for coding agents, already sitting at nearly 275k stars.

### 5. cursor/plugins (+473 stars today)
The official specification and reference plugins for the Cursor editor's plugin system.

### 6. santifer/career-ops (+855 stars today)
An open-source AI job search tool that scans job portals, scores listings with a structured A–F rubric, tailors your CV, and tracks applications.

### 7. akitaonrails/ai-memory (+335 stars today)
A long-term memory solution for agent coding CLIs, aimed at making handoff between different AI agent vendors easier.

### 8. harry0703/MoneyPrinterTurbo (+2,774 stars today)
An automated AI workflow that generates HD short videos from just a topic or keyword.

### 9. agent-substrate/substrate (+66 stars today)
The core system for "Agent Substrate," an underlying platform for running agents.

### 10. chaitanyagiri/munder-difflin (+517 stars today)
A local multi-agent harness for running coordinated AI agents on your own machine.
