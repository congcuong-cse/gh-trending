# GitHub Trending — 2026-09-25

## TL;DR
AI agents dominate today's trending list — agent skills frameworks, agentic
orchestration runtimes, and agent memory tooling take 7 of the top 10 spots.
Anthropic has two entries (a plugin directory and its public Skills repo),
and Python/TypeScript/Shell are the leading languages. A couple of outliers
break the pattern: a WiFi auditing tool and the long-running
`kubernetes-the-hard-way` classic.

## Top 10

### 1. paperclipai/paperclip (+1,853 stars today)
An open-source app for managing AI agents at work — the day's biggest riser
by stars gained.

### 2. anthropics/claude-plugins-official (+62 stars today)
Anthropic's official, curated directory of high-quality Claude Code plugins.

### 3. vectorize-io/hindsight (+1,652 stars today)
An agent memory system designed to actually learn from past interactions
rather than just store them.

### 4. obra/superpowers (+465 stars today)
An agentic skills framework paired with a software development methodology
built around it.

### 5. mattpocock/skills (+588 stars today)
A personal collection of agent skills pulled straight from the author's own
`.agents` directory.

### 6. dream-num/univer (+1,048 stars today)
An "office harness" for AI agents that bundles spreadsheets, docs, slides,
canvas, relational tables, and PDFs into one runtime.

### 7. anthropics/skills (+231 stars today)
Anthropic's public repository of Agent Skills.

### 8. androoAGI/starnet (+118 stars today)
A pixel-art desktop station where real, bring-your-own-key AI agents visibly
carry out work.

### 9. derv82/wifit3 (+168 stars today)
A USB-only, cross-platform rewrite of the Wifite wireless auditing tool.

### 10. kelseyhightower/kubernetes-the-hard-way (+105 stars today)
The well-known guide to bootstrapping Kubernetes manually, with no scripts,
still drawing steady interest.
