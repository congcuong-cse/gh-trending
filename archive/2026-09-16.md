# GitHub Trending - 2026-09-16

## TL;DR
AI agents keep driving the board, but the focus has shifted toward wrapping them in workflow infrastructure: code review pipelines, research agents, agent-aware source control, and a CRM with agents built in. Local-first AI is the other strong thread, with a pure-C engine for running frontier MoE models off disk and a fully offline voice cloning and dubbing studio both pulling in over 2,000 stars each. TypeScript leads the language mix with three entries, Rust takes two, and the rest spread across Go, C, Python, Swift, and Java. Two long-standing projects round things out: NSA's Ghidra and Homebrew, which just shipped an official macOS GUI.

## Top 10

### 1. alibaba/open-code-review (+2,756 stars today)
Alibaba's code review tool, pairing deterministic analysis pipelines with an LLM agent to produce line-level comments. Ships a multi-language ruleset covering NPEs, thread-safety, XSS, and SQL injection, and works with OpenAI- and Anthropic-compatible endpoints.

### 2. JustVugg/colibri (+2,026 stars today)
A zero-dependency inference engine written in pure C that streams mixture-of-experts weights from disk, so large frontier models can run on hardware you already own.

### 3. ever-co/ever-gauzy (+634 stars today)
An open-source business management platform bundling ERP, CRM, HRM, ATS, and project management into a single system.

### 4. debpalash/VoiceStudio (+2,072 stars today)
A fully local, open-source alternative to ElevenLabs, covering voice cloning, voice design, video dubbing, dictation, transcription, and audiobook creation across 646 languages.

### 5. Homebrew/BrewUI (+271 stars today)
Homebrew's official macOS GUI, giving the package manager a native front end instead of terminal-only use. Small but fast-growing, with the lowest star count on today's list.

### 6. melgarafael/DeskcommCRM (+193 stars today)
A self-hosted CRM built around native AI agents and WhatsApp integration, aimed at businesses that sell over chat and pitched as an alternative to Kommo, Octadesk, and Intercom.

### 7. alphaXiv/OpenResearch (+531 stars today)
A Rust tool that repurposes existing coding agents as research agents, extending the agent tooling people already run into literature and investigation work.

### 8. NationalSecurityAgency/ghidra (+725 stars today)
The NSA's open-source software reverse engineering framework, and at 77k stars by far the largest project on today's list.

### 9. danny-avila/LibreChat (+254 stars today)
A self-hostable, multi-provider chat interface supporting agents, MCP, skills, code interpretation, and model switching across most major LLM vendors.

### 10. pacifio/atlas (+91 stars today)
Source control designed for agents: run several coding agents at once, track what each one changed, and query all of it from one place.
