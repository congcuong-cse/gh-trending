# GitHub Trending — 2026-11-18

## TL;DR
Agent skills and plugins dominate: seven of the top 10 are agent-related —
skill bundles, plugin specs, agent-native CLIs, a skill evaluator, and a
multi-agent research framework (Claude Code, Cursor, Stitch MCP). Python leads with five entries, followed by TypeScript.
Biggest risers are a Claude Code bug-hunting skill bundle (+2,322) and
Google Research's multi-agent paper-writing framework (+1,529), while
classic devtools `nvm` and `uv` hold on near the bottom.

## Top 10

### 1. elementalsouls/Claude-BugHunter (+2,322 stars today)
A Claude Code skill bundle for bug hunting and red-team work — 82 skills and
15 slash commands built on disclosed-report patterns. The day's top riser.

### 2. cursor/plugins (+315 stars today)
Cursor's plugin specification plus its official plugins, a sign the editor
is opening up a formal extension ecosystem for its agent.

### 3. HKUDS/CLI-Anything (+384 stars today)
Aims to make any software "agent-native" by wrapping it in CLIs that agents
can drive, with a companion CLI-Hub.

### 4. mvanhorn/last30days-skill (+1,062 stars today)
An agent skill that researches a topic across Reddit, X, YouTube, HN,
Polymarket and the web, then writes a grounded summary.

### 5. getarcaneapp/arcane (+547 stars today)
A Docker management UI aimed at being approachable for everyone — one of the
few non-AI entries today.

### 6. NVIDIA/SkillEvaluator (+323 stars today)
A multi-tier framework for testing AI agent skills and plugins: quality gates,
overlap detection, synthetic eval data, and live measurement of skill impact.

### 7. nvm-sh/nvm (+111 stars today)
The long-standing POSIX shell script for installing and switching between
Node.js versions.

### 8. astral-sh/uv (+260 stars today)
Astral's very fast Python package and project manager, written in Rust — a
popular modern alternative to pip-based workflows.

### 9. google-research/paper-orchestra (+1,529 stars today)
A multi-agent framework from Google Research for automated AI research paper
writing.

### 10. google-labs-code/stitch-skills (+369 stars today)
A library of Agent Skills for the Stitch MCP server, built to the open Agent
Skills standard so they work across Gemini CLI, Claude Code, Cursor and others.
